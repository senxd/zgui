# Native rich text

Owned Xvfb/Openbox run passed real pointer and Enter activation of a shaped inline link, and measured a two-line paragraph at 56 logical pixels. Screenshot inspected: mixed weight/color/size, Arabic/Japanese, background, underline, strike, focused link and visible ellipsis. All owned processes exit or are cleaned by `scripts/rich_text_smoke.py`.

This is Linux software-Vulkan evidence, not macOS runtime proof. See provenance.json for the exact executed binary hash; it is not a frozen full-workspace source snapshot. GPU differential and software regression tests separately cover reactive content/decorations/overflow restoration.
